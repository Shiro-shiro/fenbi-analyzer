# 粉笔刷题分析器

抓取粉笔（fenbi）行测做题记录，按粉笔**官方分类树**统计每个题型的正确率与用时，结合目标值算出「练习优先级得分」，指导先练哪个题型。

## 它做什么

1. 用你自己的登录态从粉笔拉取做题记录：每道题对错、单题用时、知识点、全站正确率、原题年份与来源。
2. 用**官方分类树**把每道题归到「一级板块 / 二级题型」——分类直接来自粉笔的分类接口，配合每题自带的知识点 id 解析，不依赖任何人工整理的对照表。
3. 与设置里的目标正确率、目标用时、每题分值、题量权重对比，算出优先级得分并排序。
4. 一键导出 Excel 与高清 PNG。

优先级得分公式：

```
正确率差距 = max(目标正确率 − 我的正确率, 0)
用时倍数   = max(我的用时 ÷ 目标用时, 0.5)
性价比     = 正确率差距 × 用时倍数 × (每题分值 ÷ 0.8)
优先级得分 = 性价比 × (1 + 题量权重)
```

题量权重 = 该题型在模考卷中的平均出现题数 ÷ 卷面总题数，可在设置页按「出现题数 / 总题数」直接修改。

## 运行

需要 Windows + Python 3.10 以上，并安装依赖：

```
pip install PySide6 PySide6-Fluent-Widgets qrcode pillow openpyxl
```

双击 `启动程序.bat`，或在命令行运行 `python app.py`。

## 界面

左侧四项导航：

- **榜单** — 优先级榜单、抓取并计算、导出 Excel / 高清 PNG、运行日志
- **抓取与目标** — 筛选条件（专项 / 模考 / 背题、最近 N 天、国考或广西 B 类分类树）与各题型的目标值、题量权重
- **登录** — 扫码登录或手动粘贴 Cookie
- **使用说明** — 内置帮助

## 目录

```
app.py                    界面（PySide6 + Fluent Widgets）
core.py                   抓取、分类解析、榜单计算
login.py                  扫码登录 / Cookie 校验
settings.py               设置与权重的读写
exporter.py               Excel / PNG 导出
data/categories_guokao.json     国考·行政执法类 官方分类树
data/categories_guangxi.json    广西·B类 官方分类树
data/targets.json               各题型目标正确率、目标用时、每题分值
data/mock_weights_default.json  各题型默认题量权重
```

## 数据与隐私

程序只在你本机运行，抓到的数据只写本地 `data/` 目录，不会上传到任何地方。

`data/session.json` 保存你的登录态，`data/` 下的做题记录文件包含你的个人做题明细，二者都已在 `.gitignore` 中排除，不会被提交。请不要把这些文件分享给他人——登录态等同于账号密码。

抓取频率过高可能触发粉笔的临时限制，建议用测试账号调试。
