粉笔刷题分析器 · 使用说明
================================

【怎么打开】
打开桌面「粉笔刷题分析器」文件夹，双击里面的「启动程序.bat」。
公司网络屏蔽粉笔，抓取失败时请连手机热点。

【界面】
左侧是导航栏：榜单 / 抓取与目标 / 登录 / 使用说明，点一下切换页面。
「抓取与目标」一页里，上半部分是抓取设置（练习类型、时间范围、分类标准），
下半部分是各题型的目标与权重表，改完点右上角「保存」。

【第一次使用】
1. 登录页：已预置登录态（显示账号ID与保存时间）；失效时点「扫码登录」，或手动粘贴Cookie（保存前会自动验证）。
2. 抓取与目标页：选练习类型（专项/模考/背题）、时间范围、分类标准（国考·行政执法类 / 广西·B类），默认最近30天。
3. 同一页下半部分：可改每类的目标正确率、目标用时、每题分值，以及题量权重（平均出现题数/总题数130），改完点「保存」。
4. 榜单页：点「抓取并计算」，跑完表格直接显示榜单；再点「导出Excel」或「导出高清PNG」。
   抓取中可点「取消抓取」中止。

【统计口径】
- 时间：按练习【创建时间】统计（与筛选天数一致）。
- 用时：按接口逐题用时；缺失用时不当0、不参与平均；0秒题在导出的统计表中标明数量。
- 分类：按所选官方分类树。选广西B类时，国考独有分类（如"组合排列-材料"）的题不统计并明示数量。
- 未分类：匹配不到分类的题单列为"未分类"组，不会静默删除。
- 完整性：请求失败/分页超限/登录失效会明确提示，不会假装"完整完成"；失败场次见导出的"抓取失败清单"。

【优先级得分公式】
= max(目标正确率−我的正确率, 0) × max(我的用时÷目标用时, 0.5) × (每题分值÷0.8) × (1 + 题量权重)
- 题量权重 = 该题型的「平均出现题数 ÷ 总题数130」，固定取自2027国考行政执法类模考第40/41/42/43季4份卷（去重）各二级分类出现题数的平均值。
- 该权重在「抓取与目标」页以分数形式展示（分子分母都能改），可自行调整。
- 这是自定义优先级参考分，不是实际提分收益或预测分数。分数越高越值得优先练。

【榜单结构】
8列：板块 / 题型 / 答对/答题 / 我的正确率% / 目标正确率% / 我的用时(秒) / 目标用时(秒) / 优先级得分。
按优先级得分从高到低排列。榜单只读，不能直接改数据；改目标请去「抓取与目标」页。

【导出】
Excel含"优先级榜单"+"统计口径与数据质量"（+失败时"抓取失败清单"）工作表。
PNG底部标注统计口径与数据完整性警告。

【隐私】
Cookie只保存在本机 data/session.json，不外传。
【运行日志】
- 主界面不再常驻显示日志。点榜单页工具栏的「运行日志」按钮，会弹出独立窗口查看完整过程记录。
- 日志内容：运行环境、抓取参数、每页历史进度、每场失败原因、字段缺口统计（用时/全站正确率/知识点/题目来源各缺多少条）、题目状态分布、最慢的5个请求、请求统计（总数/成功/空响应/网络异常/401/429/5xx/放弃/下载量）、失败场次明细、总耗时。
- 「导出日志」保存为 txt，文件开头自动附上导出时间与程序目录，可直接发给他人排查。
- 日志窗口关闭后内容仍保留在内存里，下次打开还能看到，直到再次点「抓取并计算」重新开始。
- 常见判断：日志出现 HTTP 453 或"返回登录/风控页面"，多为网络被拦截或登录态失效——先换手机热点，再重新登录。
